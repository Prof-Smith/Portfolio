# Professional Evidence Portfolio · LION v9

This package adds the LION Market Observatory v0.9.3 as a live embedded system, while preserving:

- Three GitHub Pages project previews
- Treasury Team of One and Blackridge Mortgage Regime Lab Streamlit embeds
- Two embedded research videos and paper links
- Embedded CSS in `index.html`

## Deploy
Upload `index.html`, `.nojekyll`, and `assets/profile.jpg` to the active GitHub Pages source, replacing the existing versions. Verify the footer reads `LION v9`.

The LION preview requires the public service to remain online and permit iframe embedding. The full-system launch button remains available as a fallback.
